# AOT — Architecture of Thought

Official website for **AOT** (*Architecture of Thought*), an independent product engineering studio designing the systems through which ideas, intelligence, and technology become useful products.

## Core Focus

- AI & Intelligent Systems
- Software Engineering
- Product Development
- Automation & Workflows
- Turning ideas into real, production-ready software

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 & Vanilla Design Tokens
- **Typography**: Manrope
- **Motion**: Dual-video scroll crossfade (`globe.mp4` / `bg_network.mp4`), canvas starfield backdrop, and IntersectionObserver reveals

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Production Build

```bash
npm run build
npm run start
```
